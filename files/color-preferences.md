# Brand Colors for Civics Quiz

## Primary Palette

Keep it simple. Four colors total.

### Primary Blue
**Hex:** #2563EB

Use for:
- Buttons (primary actions)
- Links
- Progress bar fill
- Correct answer highlight
- Logo text

This is a standard blue that looks professional and trustworthy. Not too dark, not too bright.

### White
**Hex:** #FFFFFF

Use for:
- Page background
- Button text on blue buttons
- Card backgrounds
- Input field backgrounds

### Light Gray
**Hex:** #F3F4F6

Use for:
- Page background (alternative to pure white)
- Card backgrounds
- Subtle borders
- Hover states on buttons

This is Tailwind's gray-100. It is soft and easy on the eyes.

### Dark Text
**Hex:** #1F2937

Use for:
- Body text
- Headings
- Question text
- Answer option text

This is Tailwind's gray-800. Almost black but slightly softer.

## Usage Guidelines

### Buttons
- Primary button: Blue background (#2563EB), white text
- Hover state: Slightly darker blue (#1D4ED8)
- Disabled state: Light gray background, dark gray text

### Cards
- Background: White or light gray
- Border: 1px solid light gray
- Border radius: 8px (rounded corners)
- Padding: 16px to 24px

### Text
- Headings: Dark text (#1F2937), bold
- Body: Dark text (#1F2937), regular weight
- Links: Blue (#2563EB), underline on hover

### Feedback States
- Correct answer: Green background (#10B981) or blue border
- Wrong answer: Light red background (#FEE2E2) or red border

## What NOT to Use

- No gradients
- No shadows (or very subtle ones only)
- No animations that slow things down
- No more than these 4 colors
- No fancy effects

Keep it clean and fast. My students are using older phones on slow connections.
