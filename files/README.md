# Civics Quiz Page Project Assets

This folder contains all the materials needed to build a simple HTML/CSS/JS quiz page for US civics test preparation.

## What This Project Is

A single-page web application where students can practice the 100 official USCIS civics test questions. One question at a time, multiple choice, immediate feedback, score tracking.

## Folder Contents

### Documentation Files

- **project-brief.md** - The full project description and requirements
- **assets-provided.md** - Complete list of what I am providing to the freelancer
- **color-preferences.md** - Exact brand colors to use
- **hosting-notes.md** - Hosting and deployment details
- **README.md** - This file
- **image-prompts.md** - Prompts for generating the logo image

### Data Files

- **civics-questions.csv** - All 100 questions with multiple choice options and correct answers

## Expected Deliverables

The freelancer should provide:

1. **index.html** - Main quiz page
2. **style.css** - Mobile-first stylesheet
3. **script.js** - Quiz logic and question data
4. **assets/logo.png** - Logo image (or I can generate this myself using the prompts provided)

## Key Requirements

- 100 questions from the official USCIS list
- One question per screen
- 4 multiple choice options per question
- Show correct answer after selection
- Track score (X out of 100 correct)
- Mobile friendly design
- Vanilla HTML/CSS/JS (no frameworks)

## Nice to Have

- Shuffle question order on each load
- "Hard questions only" practice mode
- Progress bar
